# LeftOff — Chrome Web Store listing translations

AI-generated translations (Option A) for the 8 languages we picked, prioritized
by where LeftOff's actual users are (India is ~98% of active weekly users) and
where organic signal already exists (Japanese search traffic).

For each language: **Title**, **Short description** (shows in search results),
**Long description** (the full Overview section). Paste each into the Chrome
Web Store Developer Dashboard → Store listing → Add language, per the steps
at the bottom of this file.

The product name "LeftOff" stays untranslated everywhere — it's a brand name.

LEFTOFFの機能

✅ 続きから再生
LeftOffはすべての動画の進行状況を自動的に記憶します。いつでも戻って、止めたその瞬間から再生を再開できます。

見終わった動画にはサムネイル上にバッジが表示されます — 何を見たかいつでもわかります。

見始めたけど見終わっていない動画について通知が届くので、良いコンテンツを見逃しません。

LEFTOFFはこんな人におすすめ
• チュートリアルや講座を管理したい学習者
• 長い動画を何回かに分けて見る人
• だらだらスクロールではなく、意図を持って視聴したい人

LeftOffはあなたのデータを販売しません。動画の進行状況とキューはあなたのためだけに保存されます。無料トライアルを公平に管理するため、個人情報を含まないランダムな匿名識別子を使用しています。

## How to actually add these in the Chrome Web Store dashboard

1. Go to the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole)
2. Click into **LeftOff**
3. Click **Store listing** in the left menu
4. Look near the top for a **language selector / "Add language"** option
5. Pick a language (e.g., Hindi) from the dropdown
6. Paste in the matching **Title**, **Short description**, and **Description** from this file for that language
7. Save
8. Repeat for each language — you don't need to submit for review after every single one; you can do all 8 and submit once at the end

Do this whenever you have a few minutes — no rush, no code involved, and nothing here touches the extension itself.
